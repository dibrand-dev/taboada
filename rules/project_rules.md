# Reglas de Proyecto - Dra. Cecilia Taboada (draceciliataboada.com.ar)

## 1. Identidad Visual y UI (Estrictamente Producción)
- **Sitio de producción:** https://draceciliataboada.com.ar/
- **Diseño congelado:** El cliente aprobó definitivamente la maquetación, paleta y tipografía existentes.
- **Tipografía obligatoria:** Mantener exclusivamente Tenor Sans e Inter (definidas en layout.tsx). Queda terminantemente prohibido importar, sugerir o aplicar Outfit, Montserrat o cualquier otra fuente.
- **Paleta médica:** Mantener las variables originales de globals.css (azul marino #06162c, petróleo #296676). Queda prohibido inyectar el color #9e4d97.
- **Prohibición absoluta:** No modificar hojas de estilos, clases de Tailwind ni componentes visuales.

## 2. Contenido y Datos
- Preservar estrictamente los textos médicos, artículos, patologías y recursos reales del repositorio.
- Prohibición total de generar datos simulados o inventar contenido médico.
